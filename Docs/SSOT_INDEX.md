## 현재 제품 정의

- 제품명: PayMeter
- 형태: Local First 실시간 급여 모니터링 웹앱
- 기본 실행 형태: 반응형 Web + PWA
- 기본 저장 방식: 로컬 저장
- V1 서버: 없음
- V1 로그인 및 계정: 없음
- 핵심 입력: 급여, 근무 일정, 휴게시간, 추가수당 정책
- 핵심 출력: 현재 급여, 기간별 누적, 근무 진행 상태, 정규 근무 이후 무급 초과시간, 등록된 추가수당

## 핵심 불변 조건

- UI 갱신 횟수로 금액을 누적하지 않는다.
- 모든 금액은 시간 구간과 급여 규칙으로 재계산 가능해야 한다.
- 정규 근무 종료 이후 기본 급여 증가는 자동 중지한다.
- 정규 근무 종료 이후 유급 초과근무는 명시적 정책 또는 사용자 시작 이벤트가 있어야만 증가한다.
- 법정 수당 배율을 앱이 임의로 결정하지 않는다.
- 기본 급여 정보는 사용자 기기 로컬에 저장한다.
- 새로고침, 탭 백그라운드, PWA 재실행 후에도 동일한 입력이면 동일한 결과가 나와야 한다.
- 월, 주, 일 경계와 서머타임, 시간대 변경 같은 시간 경계를 테스트 가능한 구조로 만든다.

## 문서 변경 규칙

계산 결과에 영향을 주는 변경은 반드시 다음 중 하나 이상을 함께 갱신한다.

- 급여 계산 규칙
- 상태 전이 규칙
- 저장 스키마
- 테스트 기대값
- 구현 Phase 범위

단순 UI 문구 변경이 아닌 계산 의미 변경은 코드만 수정해서는 안 된다.
