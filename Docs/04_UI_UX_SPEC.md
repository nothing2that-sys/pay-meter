# PayMeter UI and UX Specification

## 1. UI 방향

PayMeter는 일반적인 급여 계산기보다 모니터링 Dashboard에 가깝게 보이도록 한다.

키워드:

- 실시간
- 계측기
- 숫자 중심
- 한눈에 현재 상태 확인
- 모바일 우선
- Desktop 확장
- 불필요한 장식 최소화

---

## 2. Dashboard 정보 계층

### Level 1

가장 크게 보여야 하는 정보:

- 현재 누적 급여
- 현재 상태
- 현재 증가율

예:

```
근무 중

₩ 184,375.428
+ ₩ 6.944 / sec
```

### Level 2

현재 근무 진행 정보:

- 현재 시각
- 오늘 근무 경과
- 퇴근까지 남은 시간
- 근무 진행률

### Level 3

기간 통계:

- 오늘
- 이번 주
- 이번 달
- 올해

### Level 4

분석 정보:

- 정규급여
- 추가수당
- 무료봉사 시간
- 무료봉사 환산 가치

## 5. 숫자 표시

### Current Earned

실시간 느낌을 위해 소수 원 단위 표시를 허용한다.

표시 옵션:

- 정수 원
- 소수 2자리
- Dynamic Precision

Dynamic Precision 예:

```
₩ 184,375.42
```

하단에서:

```
+ ₩ 6.944444 / sec
```

ms당 급여는 별도 상세 카드에서 보여준다.

### Rate Detail

```
시간당  ₩25,000
분당    ₩416.67
초당    ₩6.944
ms당    ₩0.006944
```

## 6. 설정 UX

설정은 한 화면에 모든 것을 몰아넣지 않는다.

권장 그룹:

1. 급여
2. 근무 일정
3. 휴게시간
4. 추가수당
5. 표시 설정
6. 데이터

첫 설정 Wizard는 최소 항목만 받는다.

### 빠른 기본 설정

Preset:

```
월~금
09:00 ~ 18:00
12:00 ~ 13:00 무급 휴게
```

사용자가 바로 편집 가능.

---

## 7. 추가근무 시작 UX

정규 종료 후 주요 CTA:

```
추가근무 시작
```

선택 시:

1. 수당 정책 선택
2. 시작 시각 확인
3. 필요 시 소급 시작 시각 조정
4. 시작

예:

```
추가근무

정책
연장근무 1.5x

시작
18:00

[시작]
```

사용자가 18:25에 앱을 확인했지만 실제 추가근무는 18:00부터였다면 시작 시각을 18:00으로 수정 가능하게 한다.

---

## 8. 퇴근 UX

`퇴근` Action은 급여와 무료봉사 카운터를 모두 종료하는 의미다.

퇴근 후 다시 추가근무를 등록해야 하는 경우 History Edit를 통해 수정 가능하게 한다.

실수 방지를 위해 진행 중 추가근무가 있다면:

```
추가근무를 종료하고 퇴근할까요?
```

처럼 명시한다.

---

## 9. 오늘 일정 변경

Dashboard에서 빠르게 접근.

예:

```
오늘만 퇴근시간 변경
18:00 -> 20:00
```

이 변경은 Daily Override이며 기본 Weekly Schedule을 수정하지 않는다.

## 10. History

History 기본 화면:

월 Calendar 또는 날짜 List.

날짜별 표시:

- 총 급여
- 정규 근무
- 유급 추가근무
- 무료봉사
- Override 여부

상세:

```
2026-09-19

09:00 ~ 12:00 정규
12:00 ~ 13:00 무급 휴게
13:00 ~ 18:00 정규
18:00 ~ 18:24 무료봉사
18:24 ~ 19:30 연장근무 1.5x

정규급여
₩200,000

추가수당
₩41,250

합계
₩241,250
```

## 11. 색과 상태

상태는 색만으로 전달하지 않는다.

항상 텍스트와 아이콘 또는 배지 의미를 같이 사용한다.

권장 의미:

- Regular Work: 정상 활성 상태
- Break: 중립
- Unpaid After Hours: 경고
- Paid Overtime: 별도 활성 상태
- Clocked Out: 완료

정확한 Color Token은 구현 시 디자인 시스템에서 정의한다.

---

## 12. 모션

실시간 숫자는 과도한 Count Up 애니메이션을 사용하지 않는다.

권장:

- 실제 계산 Snapshot 숫자를 그대로 표시
- 부드러운 소수 변화
- 상태 전환 때만 짧은 Transition

금액이 뒤늦게 애니메이션으로 따라오면서 실제값과 화면값이 달라지는 UX는 피한다.

---

## 13. 접근성

- 주요 상태는 텍스트 제공
- 충분한 Contrast
- Touch Target 최소 크기 확보
- 숫자에 tabular-nums 사용 권장
- 모션 감소 설정 지원
- Screen Reader용 상태 Label 제공

---

## 14. 사용자 문구 설정

향후 다음 상태 문구는 사용자 선택 또는 편집 가능하게 한다.

```
무료봉사 중
정규 근무 종료
초과근무 미등록
업무시간 초과
퇴근하세요
```

V1 기본은 제품 정체성을 위해 `무료봉사 중`을 사용한다.
