# PayMeter Product Requirements

## 1. Product Vision

PayMeter는 사용자의 시간을 돈의 흐름으로 시각화하는 개인용 실시간 급여 모니터다.

기존 급여 계산기가 특정 금액을 계산한 뒤 결과를 보여주는 도구라면 PayMeter는 현재 순간의 근무 상태와 급여 흐름을 지속적으로 보여준다.

핵심 질문은 다음과 같다.

- 나는 지금 돈을 벌고 있는가?
- 지금까지 오늘 얼마를 벌었는가?
- 지금 1초의 가치는 얼마인가?
- 퇴근까지 얼마를 더 벌게 되는가?
- 정규 근무가 끝났는데 계속 일하고 있다면 그 시간의 가치는 얼마인가?
- 추가수당이 적용되는 근무라면 실제로 얼마가 더 쌓이고 있는가?

## 2. Primary User

초기 대상은 일정한 급여 또는 시급 구조를 가진 개인 사용자다.

지원 급여 입력 유형:

- 연봉
- 월급
- 주급
- 일급
- 시급

향후 지원 후보:

- 건별 급여
- 프리랜서 프로젝트 금액
- 교대제 복합 급여
- 복수 직장

## 3. Core User Flow

### 3.1 첫 실행

1. 급여 유형 선택
2. 금액 입력
3. 근무 요일 지정
4. 출근 및 퇴근 시각 설정
5. 휴게시간 설정
6. 추가수당 정책 선택 또는 건너뛰기
7. 저장
8. Dashboard 진입

### 3.2 정규 근무 중

Dashboard는 다음을 표시한다.

- 실시간 누적 급여
- 초당 증가 금액
- 오늘 근무 진행률
- 현재 근무시간
- 퇴근까지 남은 시간
- 오늘 예상 최종 금액
- 오늘, 주, 월, 연 누적

### 3.3 정규 근무 종료

정규 퇴근 시각이 지나면:

- 정규 급여 증가 중지
- 상태를 `무료봉사 중` 또는 사용자 지정 문구로 전환
- 정규 종료 이후 경과시간 표시
- 해당 시간을 기본 급여 가치로 환산한 참고 금액 표시 가능
- 유급 급여 총액에는 반영하지 않음

사용자는 다음 중 하나를 선택할 수 있다.

- 퇴근
- 유급 추가근무 시작
- 오늘 근무 일정 변경

### 3.4 추가근무

사용자가 유급 추가근무를 시작하면:

- 추가근무 시작 timestamp 저장
- 선택된 수당 정책 적용
- 실시간 급여 증가 재개
- 정규급여와 추가수당을 구분 표시
- 추가근무 종료 시 Segment 확정

## 4. V1 Functional Scope

### 4.1 급여 설정

필수:

- 급여 유형
- 급여 금액
- 통화

기본 통화:

- KRW

확장 가능 구조:

- USD
- JPY
- EUR 등

### 4.2 근무 일정

지원:

- 요일별 근무 여부
- 기본 출근 시각
- 기본 퇴근 시각
- 휴게 구간 0개 이상
- 휴게시간 유급 또는 무급
- 날짜별 Override

V1에서는 동일한 평일 일정을 빠르게 적용할 수 있는 Preset을 제공한다.

예:

- 월~금
- 09:00~18:00
- 12:00~13:00 무급 휴게

### 4.3 추가수당

지원 정책:

- 기본 시급 × 배율
- 별도 시급
- 고정수당
- 시간급 + 고정수당

수당 종류 이름은 사용자 편집 가능하게 설계한다.

예:

- 연장근무
- 야간근무
- 휴일근무
- 특근

### 4.4 기간별 누적

Dashboard와 History에서 최소 다음 값을 확인할 수 있어야 한다.

- 오늘
- 이번 주
- 이번 달
- 올해

추가 후보:

- 입사 후
- 사용자 지정 기간

### 4.5 근무 상태

최소 상태:

- 출근 전
- 정규 근무 중
- 휴게 중
- 정규 근무 종료
- 무급 초과시간
- 유급 추가근무
- 퇴근 완료
- 비근무일

### 4.6 Daily Override

특정 날짜만 다음 값을 변경할 수 있어야 한다.

- 출근 시각
- 퇴근 시각
- 휴게시간
- 근무일 또는 휴무일
- 추가근무 예정
- 해당 날짜 급여 정책

기본 설정 자체를 변경하지 않고 하루만 수정할 수 있어야 한다.

## 5. Dashboard 핵심 정보

Priority 1:

- 현재 급여
- 현재 상태
- 현재 증가율
- 오늘 진행률
- 퇴근까지 남은 시간

Priority 2:

- 오늘 누적
- 주 누적
- 월 누적
- 연 누적
- 정규급여와 추가수당 분리

Priority 3:

- 무료봉사 시간
- 무료봉사 시간의 기준 급여 환산 가치
- 목표 금액까지 남은 시간
- 물건 가격의 노동시간 환산

## 6. Free Work Concept

`무료봉사`는 PayMeter의 사용자 경험 용어이며 회계상 급여로 계산하지 않는다.

정의:

- 정규 근무 종료 이후
- 유급 추가근무가 시작되지 않았고
- 사용자가 퇴근 처리를 하지 않은 상태에서
- 경과하는 시간

이 시간은 별도 통계로 누적할 수 있다.

중요:

앱은 사용자가 실제로 일을 하고 있는지 센서로 판정하지 않는다.

따라서 이 수치는 사용자가 퇴근 처리하지 않은 상태를 기준으로 하는 사용자 보조 지표다.

## 7. V1 Non Goals

V1에서는 다음을 목표로 하지 않는다.

- 법적 급여 명세서 생성
- 근로기준법 위반 판정
- 회사 급여 시스템 대체
- 원천징수 또는 세금 확정 계산
- 자동 출퇴근 위치 추적
- 서버 동기화
- 조직 관리자 기능
