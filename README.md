# PayMeter

PayMeter는 사용자가 설정한 급여와 근무시간을 기준으로 현재 벌고 있는 금액을 실시간으로 보여주는 로컬 우선 급여 모니터링 웹앱입니다.

핵심 목표는 단순 급여 계산이 아니라 다음 정보를 즉시 이해할 수 있게 보여주는 것입니다.

- 지금까지 실제로 누적된 급여
- 현재 초당, 분당, 시간당 증가 금액
- 오늘, 이번 주, 이번 달, 올해 누적 금액
- 정규 근무 진행률과 퇴근까지 남은 시간
- 정규 근무 종료 후 미등록 초과근무 시간
- 연장근무, 야간근무, 휴일근무 등 사용자 정의 추가수당
- 근무시간 대비 돈의 가치를 직관적으로 보여주는 지표

## 기본 원칙

- Local First
- 계정 없이 사용 가능
- V1은 서버 없이 동작
- 설정은 로컬에 저장
- 금액 계산은 타이머 tick 누적이 아니라 시간 구간 적분 방식 사용
- 정규 근무시간 외에는 기본 급여 증가 중지
- 추가수당은 명시적으로 등록된 경우에만 반영
- 법정 수당을 자동 추정하지 않고 사용자가 직접 정책을 설정
- 모든 계산 규칙은 재현 가능하고 테스트 가능해야 함
- PWA 설치를 지원하는 것을 목표로 함
